System architecture

SkinType AI — how the pipeline works

A full-stack computer-vision system: one face photo in, a structured per-condition skin analysis and a rule-based skincare plan out. A vanilla-JS single-page app talks to a FastAPI backend that orchestrates a stack of vision models, persists results to SQLite, and pulls live environment data from Open-Meteo.

The organising principle is provenance. Every value the API returns is traceable to a named checkpoint, a documented deterministic formula, or an explicit not available marker — the diagrams below colour each component by which of those it is.
